Seren Nixgate

Personal Kodi repository for a modified Seren build (Simkl + MDBList integration), plus its companion context.seren context-menu add-on.

1. Add this page as a source in Kodi

In Kodi: Settings → File Manager → Add source, then enter this exact path:

https://minhgi.github.io/repository.seren-nixgate/

Give it any name (e.g. "Seren Nixgate") and select OK.

2. Install the repository add-on

In Kodi: Add-ons → Install from zip file → select the source you just added → select:

repository.seren-nixgate-1.0.0.zip

3. Install Seren from the repository

In Kodi: Add-ons → Install from repository → Seren Nixgate → Video add-ons → Seren.

context.seren installs automatically alongside it as a required dependency.

Whether the original (non-fork) Seren 3.0.62 needs to be installed first, as it does with the manual zip method, hasn't been tested via this repository path. If step 3 fails or behaves oddly, install Seren 3.0.62 from Kodi's official Add-on repository first, then retry step 3.

Once the repository add-on is installed, Kodi checks this repository for updates automatically — no need to repeat these steps for future Seren releases.
