# Seren Nixgate Repo

Personal Kodi repository for a modified Seren build (Simkl + MDBList integration), plus its companion `context.seren` context-menu add-on.

## Install

1. Download `repository.seren-nixgate-1.0.0.zip` from `packages/repository.seren-nixgate/` in this repo.
2. In Kodi: **Add-ons -> Install from zip file**, select the downloaded zip.
3. **Install from repository -> Seren Nixgate Repo -> Video add-ons -> Seren** (and optionally `context.seren`).

Once the repository add-on is installed, Kodi checks this repo for updates automatically.
